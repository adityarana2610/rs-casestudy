Why is Recall@10 Small by Construction?

Recall@10 measures hits / (all other items in seed subcategory). In the Amazon catalog, each subcategory contains 300 to 1,200 items. With only 10 retrieval slots, maximum theoretical recall is bounded at ~0.03. Recall is used strictly for relative cross-model comparison.

The Euclidean vs Cosine Identity (99.6%)

When document vectors are L2-normalized to unit norm (||x|| = 1), Euclidean distance and cosine similarity are strictly monotonic: d_E² = 2 - 2·cos(u, v). In 99.6% of seeds, top-10 sets are identical; the 0.4% discrepancy is due to floating point tie-breaking.

KEY BREAKTHROUGH

Metadata Fusion: Product Name + About Product

Concatenating title and product description increases P@10 from 0.538 to 0.586 (+4.8% paired lift, p < 0.001) and NDCG@10 from 0.558 to 0.603. Description text supplies domain attributes (material, dimensions, age grade) missing in sparse titles.

CONTROL STUDY

Title-Only Control Separates Effects

When Word2Vec is trained on the fused corpus but only the title is pooled at retrieval, P@10 reaches 0.560 (+2.2%). This proves 46% of the fusion gain comes from superior word embeddings, and 54% from richer query representations.

POOLING EFFECT

Sum-Pooling vs Mean-Pooling

Mean-pooling drops P@10 by 1.5% under Euclidean distance (0.523 vs 0.538). Sum-pooling preserves word count weight, implicitly encoding document length cues relevant in catalog search.

MATHEMATICAL FORMULATIONS

From-Scratch NumPy Implementation (Equations 1–8)

Faithful reproduction of Oprea et al. Vectorizer and similarity metrics built without high-level library shortcuts.

Paper Eq. 1

Cosine Similarity

sim(A, B) = (A · Bᵀ) / (||A||₂ · ||B||₂)

Implemented using vectorized matrix multiplication dot = A @ B.T and broadcasting row norms. Numerical guard max(na * nb, 1e-10) prevents division by zero for sparse all-zero vectors.

def cosine_sim_scratch(A, B):
  dot = A @ B.T
  na = np.linalg.norm(A, axis=1, keepdims=True)
  nb = np.linalg.norm(B, axis=1, keepdims=True).T
  return dot / np.maximum(na * nb, 1e-10)
Paper Eq. 2

Manhattan Distance (L1)

d_M(A, B) = Σ |A_i - B_i|

Sum of absolute coordinate differences. Sensitive to vector dimensionality and unnormalized embedding scale, explaining large values for 300d embeddings.

def manhattan_dist_scratch(A, B):
  out = np.zeros((A.shape[0], B.shape[0]), dtype=np.float32)
  for i, row in enumerate(A):
    out[i] = np.abs(B - row).sum(axis=1)
  return out
Paper Eq. 3

Euclidean Distance (L2)

d_E(A, B) = sqrt(||A||² + ||B||² - 2(A · Bᵀ))

Computed via identity expansion to avoid allocating O(N·M·D) intermediate tensors, running 40x faster than naive difference arrays.

def euclidean_dist_scratch(A, B):
  a_sq = (A ** 2).sum(axis=1, keepdims=True)
  b_sq = (B ** 2).sum(axis=1, keepdims=True).T
  return np.sqrt(np.maximum(a_sq + b_sq - 2.0 * (A @ B.T), 0.0))
Paper Eq. 6–8

Scratch TF-IDF Vectorizer

TF(t, d) = f(t, d)/|d|, IDF(t) = log(N / df(t))

Vocabulary is injected directly from CountVectorizer to guarantee identical vocabulary space, eliminating vocabulary mismatch confounds. Rows are strictly L2-normalized.

class ScratchTFIDF:
  tf[i, j] = c / len(toks)
  idf = np.log(N / np.maximum(dfc, 1.0))
  X = tf * idf
